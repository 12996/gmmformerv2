## 实现要点（我们实际跑的代码）
文本投影（保留序列，不是 EOT）：
```
x = token_embedding(tokens) + positional_embedding
x = transformer(x, attn_mask=attn_mask)
x = ln_final(x)
x = x @ text_projection   # 整段 token
seq = x[i, :length_i]     # strip pad，写入 h5
```
loader：visual_feature=='clip' 时
```
visual = FeatureData/charades_clip_L14.h5
text   = TextData/charades_clip_L14.h5   # 已被投影 h5 原子替换
```
DyGMMBlock TC（E1 已删 mean 覆盖，E2 沿用）：
```
weight = softmax(...)
out = torch.sum(oo * weight.unsqueeze(2).repeat(...), dim=-1)
return out
# 老师 zip 里曾有：out = torch.mean(oo, dim=-1).squeeze() 覆盖加权，E1 删掉后 I3D 从 73.5→78.4
```
early stop：
```
if val SumR > best: es_cnt=0; save best.ckpt
else: es_cnt += 1
if es_cnt > max_es_cnt(10): Early Stop; exit(0)
```
hard negative：epoch>=20 时 criterion.cfg['use_hard_negative']=True（E1 同样如此仍到 78.4）

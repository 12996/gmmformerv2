## 1. 任务与设定

PRVR：给定文本查询，对未剪视频排序。论文方法为帧/片段双分支 + TC-GMMBlock + 查询多样损失 + 最优匹配损失。官方命令 `python main.py -d {cha,act,tvr}`，batch 128，最多 100 epoch，early stop 10。视觉为 I3D（Charades / ActivityNet）或 I3D+ResNet152（TVR），文本为 RoBERTa。特征来自 MS-SL（Drive / 百度网盘同一套）。

实验室在老师 zip 上发现 `DyGMMBlock` 用 `torch.mean` 覆盖了官方加权 sum。删掉该覆盖后 Charades SumR 从 73.5 升到 78.4。后续 Table 1 与 E4 均使用已修 TC。

## 2. Table 1 复现（I3D+RoBERTa）

| 数据集 | 论文 R@1/5/10/100 / SumR | 我们 | ΔSumR |
|---|---|---|---|
| Charades-STA | 2.5 / 8.6 / 13.9 / 53.2 / **78.2** | 2.4 / 8.8 / 14.2 / 53.0 / **78.4** | +0.2 |
| ActivityNet | 8.9 / 27.1 / 40.2 / 78.7 / **154.9** | 9.2 / 27.3 / 39.8 / 78.7 / **155.0** | +0.1 |
| TVR | 16.2 / 37.6 / 48.8 / 86.4 / **189.1** | 15.3 / 36.0 / 47.6 / 86.4 / **185.3** | −3.8 |

- Charades、ActivityNet 与论文同量级；TVR 的 R@100 贴上 86.4，SumR 低 3.8。TVR 跑满 100 epoch（无 Early Stop）；从 `best.ckpt` resume 到 200 后 Early Stop，Best **仍为 185.3**。
- 证据：`VERIFY.md`；`tmp/i3d_tc_seed9527`、`tmp/act_i3d_seed9527`、`tmp/tvr_i3d_seed9527`。

## 3. E4 对照：I3D 视觉 + CLIP 文本（另表）

结构与论文相同（已修 TC），查询改为 CLIP-B/32：`ln_final @ text_projection` 的 **token 序列**（不是 zip 内 EOT 单向量）。seed 9527。

| 数据集 | I3D+RoBERTa（我们） | E4 I3D+CLIP 文本 |
|---|---|---|
| Charades | 78.4 | **80.1**（2.4 / 9.3 / 15.5 / 52.8） |
| ActivityNet | 155.0 | **155.2**（9.0 / 27.6 / 40.2 / 78.4） |
| TVR | 185.3 | **178.6**（14.6 / 34.4 / 45.7 / 83.9） |

Charades 上 CLIP 文本优于 RoBERTa；ActivityNet 打平；TVR 低约 6.7。不能据此宣称 CLIP 查询全面更好。代码与配置冻结在 `experiments/e4_freeze/`，远程 `tmp/*cliptext_e4_seed9527` 未覆盖。

另：CLIP 视觉 + CLIP 文本（E2）Charades SumR **68.0**；CLIP 视觉 + RoBERTa（E3）**65.4**。与 Table 1 不可比。

## 4. TVR 上针对 E4 的后续刀

固定 I3D 视觉与 GMMFormer 主干，一次一变量：

| 实验 | 改动 | SumR | vs E4 178.6 |
|---|---|---|---|
| 原 E4 | 官方 tvr 超参，lr 3e-4，sft 0.09 | **178.6** | — |
| lr 2e-4 | 只改学习率 | 176.3 | −2.3 |
| sft 0.6 | 只改 TC 温度 | 178.8 | +0.2 |
| EOT | 同源抽取改为单 EOT | 165.3 | −13.3 |
| qbert bypass | 旁路 query BertAttention | 174.7 | −3.9 |

结论（与 GPT-6 共识一致）：在固定结构 + CLIP-B/32 查询范围内，lr/sft 几乎补不回 TVR 缺口；token 序列优于 EOT；旁路查询再编码块也无收益。本轮该搜索已收口。Table 1 仍只认 I3D+RoBERTa。

## 5. 局限

- 单 seed。
- Charades I3D 特征来自 A3PRVR `i3d_feat` + 自抽 RoBERTa，不是论文发布文件的逐字节同一份；但 SumR 已贴上论文。
- TVR/ActivityNet 用 MS-SL 官方 zip/tar。
- 未复现论文效率表（T2）与插件实验（T6）。
- 未宣称超过 SOTA。

## 实际代码（请按这个架构想下一刀）

Configs/cha.py 当前是 E3：visual_feature=clip, visual_feat_dim=512, q_feat_size=1024, hidden_size=384, map_size=32, max_ctx_l=128, clip_scale_w=0.7, frame_scale_w=0.3, lr=2e-4, hard_negative_start_epoch=20, max_es_cnt=10。

builder.py：
- visual_feature in (i3d, i3d_rgb_lgi): FeatureData/charades_i3d.h5 + TextData/roberta_charades_query_feat.hdf5, dims 1024/1024, is_clip=True（走 h5 采样）
- visual_feature==clip: FeatureData/charades_clip_L14.h5 + TextData/roberta_charades_query_feat.hdf5（E3；E2 时 text 曾是 charades_clip_L14.h5 投影 token 序列）

GMMFormerV2_Net：query_input_proj / clip_input_proj / frame_input_proj 都把输入投到 hidden 384；clip_encoder=DyGMMBlock(frame_len=32)；frame_encoder_1=DyGMMBlock(frame_len=128)；query 走 BertAttention + modular_vector_mapping。

DyGMMBlock.forward 现在是官方加权（E1 已删 mean 覆盖）：
```
weight = softmax(...)
out = torch.sum(oo * weight.unsqueeze(2).repeat(1, 1, oo.shape[2], 1), dim=-1)
return out
```
老师 zip 里曾有 `out = torch.mean(oo, dim=-1).squeeze()` 盖掉加权，删掉后 I3D 从 73.5→78.4。

CLIP 文本抽取（E2，不在 vendor）：
```
x = token_embedding(tokens)+pos
x = transformer(x, attn_mask=attn_mask)
x = ln_final(x)
x = x @ text_projection   # 整段 token，不是单 EOT
seq = x[i, :length_i]
```

main.py：epoch>=20 开 hard negative；val SumR 不升则 es_cnt+1，>10 就 Early Stop。
